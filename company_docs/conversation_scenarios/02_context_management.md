# 场景 02：上下文管理与限制

## 场景描述

探讨长对话中上下文如何管理、何时截断、以及用户如何手动控制。

## 上下文限制机制

### 滑动窗口参数
```python
max_messages = 20   # 最多消息数
max_chars = 8000    # 最多字符数
```

### 截断策略
1. 优先保留最近的消息
2. 从最早的消息开始移除
3. System Prompt 始终保留

## 对话示例：长对话截断

```
# 假设已有 19 条历史消息

用户：@gemini 第 20 条消息
Gemini：回复第 20 条

用户：@gemini 第 21 条消息
# 此时第 1 条消息被移除
# LLM 只看到消息 2-21
Gemini：回复第 21 条

用户：@gemini 你还记得我们最开始讨论什么吗？
Gemini：抱歉，我无法回忆起更早的对话内容...
```

## 对话示例：手动重置

### /reset - 完全重置
```
用户：@gemini /reset
Gemini：✅ 已彻底重置所有对话历史和上下文（删除了 15 条历史记录）
        🔄 现在是一个全新的开始，机器人已不再记得之前的任何对话。

用户：@gemini 我们之前讨论什么？
Gemini：你好！这是我们的第一次对话，请问有什么可以帮助你的？
```

### /new - 清除文件上下文
```
用户：[发送 PDF 文件]
用户：@gemini 总结一下这个文档
Gemini：这是一份关于...的文档

用户：@gemini /new
Gemini：✅ 已清除文件上下文，开始新对话
        💡 之前的文件将不再自动使用，如需引用请重新发送或 Quote

用户：@gemini 帮我总结文档
Gemini：你好！请先发送需要总结的文档。
# 文件上下文已清除，但对话历史仍保留
```

## 上下文隔离

### 按 chat_id 隔离
```
群聊 A (chat_id: group_A):
  用户 1：讨论 Python
  Gemini：Python 是...
  
群聊 B (chat_id: group_B):
  用户 2：讨论 JavaScript
  Gemini：JavaScript 是...
  
# 两个群聊的上下文完全独立
```

### 跨 Bot 共享
```
群聊 A:
  用户：@gemini Python 是什么？
  Gemini：Python 是一种编程语言...
  
  用户：@chatgpt 继续解释
  ChatGPT：好的，继续之前的话题，Python...
  
# 同一群聊的不同 Bot 共享上下文
# （因为 chat_id 相同）
```

## 关键决策点

| 问题 | 当前策略 | 备选方案 |
|-----|---------|---------|
| 何时截断？ | 超过 20 条或 8000 字符 | 可配置 |
| 截断什么？ | 最早的消息 | 可按重要性 |
| Bot 间共享？ | 是（同 chat_id） | 可按 bot_type 隔离 |
| 重置粒度？ | /reset 全清，/new 仅文件 | 可更细化 |
